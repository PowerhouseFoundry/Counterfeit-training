WEST SILC POWERHOUSE — BANKNOTE TRAINING APP (IPAD EDITION)
====================================================================

PURPOSE
A visual, fictional educational workplace-training app that teaches
learners how to check UK Bank of England polymer banknotes.

FEATURES
- One-screen layout for iPad landscape and portrait: no page scrolling.
- Smart layout also supports tablet, desktop and smaller mobile screens.
- 9 interactive slides: LOOK / TILT / FEEL / CHECK, UV and safety.
- 4 denominations shown with photographs/teaching illustrations.
- A tilting hologram simulation and a practical check-off activity.
- 10-question interactive quiz with explanations and final score.
- Optional text-to-speech using the device's voice capabilities.
- Reference poster and an optional fullscreen view.
- No logins, tracking, Firebase, data storage or internet needed.

HOW TO USE
Quickest: open the standalone file Powerhouse_Banknote_Training_iPad.html
in a browser. All images and code are inside that one file.

To publish on GitHub Pages or Firebase Hosting, upload all these files:
  index.html
  styles.css
  app.js
  assets/  (keep every file in this folder)

No npm build, server or database configuration is needed. You can upload
the app folder intact to any static hosting service.

On iPad you can use the app in landscape or portrait. For an immersive
experience, use Safari's full screen (where supported) or add the hosted
web page to the Home Screen. On smaller phone screens, normal scrolling
may still be used so text remains readable.

The generated banknote images are classroom teaching illustrations. They
must not be used to authenticate real money. Practise with physical notes
and the Bank of England's own guidance, with staff support.
